- **What happened:** two-digit-year rows are "added rows" that never move a main (four-digit) row, and among themselves they mirror main's bookkeeping (`partner_2d`, `adj_labeled_2d`, `cur_flows_2d` / `cur_added_2d` / `cur_oneline_2d`, `edges_2d`). But a table BOUNDARY (`flush()`) is still decided by main's header: main's header text runs on over the first two-digit rows, so under an UNLABELED header repeated per page, a page whose two-digit rows print an `ADJ` token reads as "labeled" to main, and main's rule can split one two-digit table into two (or keep two as one) where its four-digit twin would not. `adj_labeled_2d` is recomputed on each header but never causes a boundary. Effect: column-shift verdicts and unlabeled-ADJ flags of TWO-DIGIT rows only; never a main reading. Measured in review round 3: 0 of 3,000 random twin tables differ under labeled headers, 72-284 of 3,000 under unlabeled ones.
- **Failing inputs (from review round 3; use as tests):** `HDR_FULL_NO_ADJ` (tests/test_woi_parser.py) repeated on pages 1 and 2:
  - (A) page 1: 15 two-digit rows with negative Flow, one of them followed by a literal `ADJ` line; page 2: 15 two-digit rows with negative Flow, no ADJ. Four-digit twin: one table, all 30 rejected (100% negative). Two-digit today: split at page 2, each pool 15 (< 20 minimum), all 30 shifted readings emitted.
  - (C) page 1: `AHW1 ... ADJ` then `AHW9 10/1/25 9:00`; page 2: `AHW9 10/1/25 9:00`. Twin: the page-2 row is ADJ (paired with page 1's last row). Two-digit today: `adj=False`.
  - Related (same section of the ADR): where main's own header text takes a first one-line row's `ADJ` as a label (the #167 accepted case), a two-digit table reads the header as printed instead, so the two can differ there too. Decide which behavior is right for the two-digit chain and document it.
- **Do:** (a) give the two-digit chain its own table boundary, decided from the header cut at the first row (`adj_labeled_2d`, plus the same layout / alias / cols tests main uses), WITHOUT changing when main flushes or what main emits, and without reordering main's readings in `out.readings`; (b) extend `tests/test_woi_two_digit_year.py`: cases A and C, and the seeded twin test (`test_two_digit_tables_read_like_their_four_digit_twins`) widened to multi-page UNLABELED headers with mixed ADJ tokens (the twin property must then hold there too, except any documented exception from the "Related" point); (c) ADR 005 addendum closing the open item.
