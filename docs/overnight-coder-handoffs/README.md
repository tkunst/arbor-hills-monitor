# Overnight-coder handoffs

Task specs for the overnight-coder loop (see `docs/overnight-coder.md`).

- **New or open handoffs** go at the top level of this folder.
- **Finished handoffs** (built and merged, or closed by a decision) move to
  `archive/`, keeping their filename, so code comments and ADRs can still cite them.

Everything here is excluded from markdownlint (`.markdownlint-cli2.yaml`).
As of 2026-11-01 every handoff is in `archive/`.
