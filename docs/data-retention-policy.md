# Data Retention Policy

Landfill Records Project LLC (publisher of arborhillsmonitor.org)
Effective: October 24, 2026

This is the retention policy referred to in Section 7 of the site's Privacy Policy
(`site/privacy-policy/`). It covers the personal data the project holds. Public
regulatory records and the monitoring data built from them are not personal data
and are kept permanently as the public record.

| Data | Where it is kept | How long |
|---|---|---|
| Alert and Sunday digest recipients (name, e-mail address, and for some digest recipients a telephone number) | Private configuration file and encrypted GitHub settings | While you are a recipient. Removed when you unsubscribe or ask us to remove you. |
| "Do not send" list (contact information of anyone who unsubscribed) | Private configuration file and encrypted GitHub settings | Kept indefinitely, so that we never send to you again. |
| E-mail you send us (feedback, questions, privacy requests) | Gmail | Kept as long as needed to respond and to keep a record of what was asked and answered. You can ask us to delete it, unless we need to keep it for a reason below. |
| Correction requests | Gmail and the public Corrections log | The request is kept as a record. The Corrections log shows what was corrected, not who asked. |
| Privacy requests (access, correction, deletion) and our responses | Gmail | At least 2 years after the request is closed, as a record that we handled it. |
| Survey responses (if we run surveys in the future) | Where the survey says | No longer than needed for that survey; we will state the period when we collect them. |
| Technical data (IP address, browser, device) | Held by Cloudflare and GitHub, not by us | Under their own retention policies. We see only aggregate traffic counts. |
| Search statistics | Google Search Console | Aggregate only, under Google's retention. |

## Holds

If there is a complaint, a legal claim, a subpoena, or a reasonable prospect of
litigation, we keep the relevant data until the matter is resolved, even if this
table says it would otherwise be deleted.

## Deletion

When data reaches the end of its period, or you ask us to delete it and no hold
applies, we delete it from the configuration file, GitHub settings, and Gmail.
Copies in backups are overwritten in the normal course.

## Requests

To ask about this policy or to request deletion, e-mail
<corrections@arborhillsmonitor.org>.
